This release of Glide improves mouse handling, removes redundant group bars, and fixes resizing in experimental scrolling layouts.

### Bug Fixes

* Recover focus-follows-mouse and scrolling after macOS disables input monitoring, without restarting Glide ([#288](https://github.com/tmandry/glide/pull/288)).
* Remove redundant group bars when closing the last window beside a group in a tree layout ([#259](https://github.com/tmandry/glide/pull/259)).

### Experimental Features

* Fix incorrect resizing and overlapping windows in the experimental scroll layout ([#279](https://github.com/tmandry/glide/pull/279)).
